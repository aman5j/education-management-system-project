# Education Management System

Production-style Education Management System built with MERN.

## Technology

### Frontend

- React.js
- Vite
- JavaScript
- React Router
- Axios
- Normal CSS

### Backend

- Node.js
- Express.js
- MongoDB
- MongoDB Atlas
- Mongoose
- JWT
- bcryptjs

## Roles

The system contains exactly three roles:

1. admin
2. website_editor
3. student
